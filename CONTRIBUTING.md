# Contributing

Open an issue to discuss substantial changes. Fork the repository, create a branch,
and keep pull requests focused. Include the problem, solution, and validation.
Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run build` before submitting.
Test changes to migrations against both a fresh and a populated local database.
Never include credentials, production data, or customer identifiers in examples.
Contributions are submitted under this project's MIT license. Preserve notices
for any third-party code you add. Report vulnerabilities privately as described in SECURITY.md.
